# v0.2.0-rc.2 draft

This draft follows the immutable `v0.2.0-rc.1` tag. It repairs the DeepSeek
Harness scenario and Campaign model profiles, adds the locked loopback-Qwen Harness
entry, installs Harness dependencies from `package-lock.json` during the image build,
and adds a fail-closed release identity validator plus source-snapshot/online-build path.

The draft is intentionally not server-deployment-ready. H7.0 must populate the
Node and Ollama repository digests plus the four final image IDs, reseal the
manifest, and then pass `scripts/validate_release_candidate.py
--require-deployment-ready`. Real-model server acceptance remains excluded.
