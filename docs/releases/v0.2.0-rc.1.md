# v0.2.0-rc.1

This release candidate combines the Stage 6 repair baseline at `34a2789` with
the DeepSeek Harness H0-H6 implementation. Both Agent runtimes use the same
frozen Office V2 world, tool surface, trace, recording, replay, coverage and
Campaign contracts.

The Judge implementation and its golden data remain outside this candidate.
Real-model server acceptance is also not claimed yet. The next deployment must
check out the exact release tag, fetch the locked Qwen model from the official
Ollama registry, verify complete digests, and build both Agent images on the
server.

The machine-readable identity and deployment boundary are frozen in
`config/releases/v0.2.0-rc.1.json`.
