## 2. 状态规则

任务状态只使用 `DRAFT`、`READY`、`IN_PROGRESS`、`BLOCKED`、`DONE`。

- 当前所有子任务均为 `DRAFT`，表示拆解尚待用户 review。
- 用户批准本 TASK 后，任务计划改为 `READY`；第一个无依赖子任务改为 `READY`，其余子任务在前置依赖完成前保持 `BLOCKED`。
- 开始执行某个子任务时改为 `IN_PROGRESS`。
- 只有 checklist、证据记录和对应交付内容全部完成后，子任务才能改为 `DONE`。
- 如果缺少权限、环境、定义或判定证据，使用 `BLOCKED`，并在文档中记录阻塞原因；不得把未知项猜成结论。
- 如果审计发现需要改变范围或产品语义，停止执行并返回 SPEC 讨论阶段。
