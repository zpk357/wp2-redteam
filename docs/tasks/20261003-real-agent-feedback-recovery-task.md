- 数据流：冻结计划/材料/身份/预算 → 首轮检查点 → 模型返回及待执行调用 → 工具执行 → 状态与结果检查点 → 后续模型回合。

- [ ] 工具结果与对应世界状态属于同一恢复边界；先保存再进入后续模型回合。
- [ ] 恢复复用已完成结果；不重新询问模型生成已经保存的工具调用，不重复结算覆盖。
- [ ] 明确仅支持隔离的合成 Office 世界。若提交结果不确定且无法从持久状态确认，标记 unresolved 并停止，不自动重发可能产生外部副作用的请求。

- [ ] 失败调用、预算耗尽、损坏检查点、重复启动和不匹配计划均有测试。
- [ ] 本地通过后服务器进行同类真实 Provider 恢复 smoke；仅要求保存的调用和已提交状态一致，不要求重新生成的模型输出逐字一致。

风险/失败/回滚：只写日志、不保存世界状态或丢失批量调用游标均属失败；禁用新恢复入口并保留产物，禁止覆盖旧证据。

## RA-CLOSE-02：真实跨 Episode 反馈闭环

- 数据流：真实 trace/bridge → 行为、风险、联合覆盖 → 冻结反馈收据 → 同模型 LLM selector → 下一集计划 → Agent。

- [ ] guided 保存反馈输入/摘要、选择器请求、原始响应和验证后的计划，证明第 N 集事实进入 N+1 请求。

- [ ] 至少连续三集契约集成；random 注入历史读取哨兵，证明无读取。
- [ ] 两臂除反馈外的菜单、模型、预算、Agent 输入及 Oracle 配置对齐。
- [ ] 完成服务器连续多集小规模 smoke；不据此声称 guided 优于 random。

风险/失败/回滚：把已覆盖标成缺口、反馈只用于报表、按计划标签造覆盖、削弱随机基线均失败；保留旧单集 smoke，禁用未通过的新调度入口。
