| `docs` 与根目录文档 | SPEC/TASK/计划/现状/交接/说明/报告；文档内部引用与权威身份 | 文本过时、原始证据、已批准有效契约分别判断；保留 LOG/索引 |

只新增盘点输出；不会改变“输入 → 选择/生成 → Agent → 工具/状态/轨迹 → Oracle → 链/四维等级/增量 → 下一轮”的数据流。当前四条硬设计与随机公平性是保护依据，不从旧文档反向生成需求。
