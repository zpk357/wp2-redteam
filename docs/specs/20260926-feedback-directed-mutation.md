# SPEC-SOC-FDM-20260926：让覆盖反馈直接影响变异

- 状态：`APPROVED`（2026-09-26；用户批准本 SPEC、逐对违规成功率硬门槛及[参数补充规格](20260926-feedback-directed-mutation-parameters.md)）；TASK 待单独确认。
- 上位规格：[产品规格](../SPEC.md) `G-02/03/04`、`FR-FUZZ-01/03/05`、`FR-EXP-01..05`、`AC-04/05/06`。
- 依据：只读审计，源码基线 `1987333`。
- 本稿是需求与方案，不是 TASK；不授权服务器运行，不修改旧实验结论。此前“写 task”属于报告修复，不作为本稿批准依据。

## 1. 已确认的目标与待验证假设

用户当前优先目标是：相同资源预算和可信口径下，`coverage_guided` 比 `random_evolution`
获得更多联合覆盖、更高覆盖效率。风险和行为仍须分别解释；W/U 是独立安全效用。本轮实验整体通过还要求每一完整配对中，引导臂的可判定 Episode 违规成功率 `W/(W+F)` 非零，且高于对应随机演化臂；`W/N_op` 另列。旧结果不改名为成功，不承诺任何实现必然胜出。

已知事实：当前反馈影响父选择，具体编辑仍均匀抽样，生成模型不见历史覆盖摘要；选择器还存在
已复现的空维度未回退问题。目标强化和八手法均已尝试，未得到完整的新两臂比较。

**H-FDM（待测）**：在有可变真实行为分支的任务上，利用覆盖历史选择修改位置及语义探索意图，
比仅按覆盖选父、再随机修改更可能产生有用子代；与同能力随机演化的差异需在新实验验证。

## 2. 可选办法及优先级

| 办法 | 能解决什么 | 本稿决定 |
|---|---|---|
| 修复已批准选择规则的实现偏差 | 减少有合格父时仍退回随机根的机会 | 第一优先；单独验收，不能承诺收益 |
| 覆盖反馈进入编辑位置与变异意图 | 直接加强两臂唯一应有的差异：历史信息的使用 | 推荐的新机制 |
| 配对共同起始输入、完整多种子比较 | 降低根样本运气和执行顺序噪声 | 正式协议冻结前准备；不以历史赢家选根 |
| 更多具有自然业务分支的任务组合 | 当前场景变化若不能影响执行，提供可探索的空间 | 两轮开发仍无新增时的备选；另行规格 |
| 确定性 Agent / 有限候选池实验 | 低成本证明选择器在已知分支上能工作 | 本地机制验证，不充当真实 LLM 优势 |
| 继续统一加强攻击话术或更换被测模型 | 可能改变攻击难度，但不直接加强引导相对能力 | 本稿不采用；以后需独立身份与比较 |
| 直接增加相同旧实验的运行量 | 改善不确定性，无法修复反馈利用问题 | 当前不采用 |

## 3. 需求契约

### FDM-01：先恢复已批准的空索引回退

沿 `SOC-FBK-09` 的 R/B/R/J 循环检查其他启用维度，找到合格父才执行局部变异；仅在计划根机会
或全部启用维度均不可用时根重启。重复 R 去重检查但不改变轮换时钟。记录实际选中维度与回退理由。
共享日程、维度含义、资格校验、随机演化规则不因该修复改变。

父冷却的源父归因另作合同澄清及真实多子代反例验证；不得以重置冷却或隐去失败取得增益。

### FDM-02：新版本中允许反馈选择合法编辑位置

复用现有合法操作/位置枚举与准入，保持六种操作、容量、固定资产及每机会一次编辑的边界。
两臂拥有完全相同的合法集合。引导结合已见 B/R/J、重复情况及可验证的父材料暴露证据选位置；
随机继续从同一集合不读执行反馈地选择。不得给引导独占的新工具、槽位或编辑能力。

第一版选择规则须在 TASK 前固定：按启用覆盖维度轮换、优先实际可影响后续决策的已读位置，
同时保留对未读位置的探索概率；无有效证据时退回共同随机编辑。概率、同分规则和缺证处理不得看结果后更改。
未读位置不永久禁用，父代暴露不保证子代会再次暴露。

### FDM-03：生成请求接收有界的公开反馈摘要

新增版本化反馈投影，内容限于经证据校验的公开描述：父候选实际暴露的注册槽、公开工具动作类别、
有无后续行动窗口、重复观察，以及在公开语义目录内选出的探索意图。每项附宿主侧来源引用与投影摘要。
无证据填 unknown，不把“没观察到”写成“确定没发生”；文本改动是否被读需比较实际返回与物化摘要。

原始 R/J 键、敏感类别与资源的隐藏绑定、私有正文/值、Oracle 隐藏标签、标准答案和指定正确工具路线
不进入 Provider。用显式字段白名单和**完整最终请求**私值校验保护边界，不能只校验旧 PublicProjection。
不把工具失败内容或模型推理原文直接贴回去，不新增 LLM Judge 或额外反思调用。

### FDM-04：共同变异能力与真实信息差

两臂使用同一个 Provider 模型、提示模板、公开意图目录和一次生成/最多一次格式修复上限。
引导用历史覆盖选择意图，随机在同一目录按预冻结无反馈规则选择；随机历史字段为空，不能填伪造反馈。
静态任务与攻击方向/手法仍共享，随机可构造引导可构造的任一合法候选。
反馈摘要 token、生成失败和格式修复计入真实成本，不用等 Episode 数冒充等成本。

### FDM-05：探索意图不等于覆盖事实

意图只能来自冻结的公开任务、槽和工具能力语义；“尚未观察到”不意味着该状态必然可达。
不得枚举 R×B×J 笛卡尔积并把不存在的关系当作缺口。行为新增、风险新增与逐事件联合新增
继续由原执行证据和 coverage 提取器确定，不给关键词、提示变化或“听从建议”发奖励。
R/B/J 分维度保留，不压成不可解释总分；新机制的具体排序顺序须预先固定。

### FDM-06：不可变的被测条件与新身份

当前 Agent prompt v2 和 `material-search-v4` 是待冻结的候选基线；正式运行包须核查用户最新决定，
两臂一致使用同一版本。本稿不再修改被测 Agent 提示、权限、Oracle、覆盖键、固定资料或 FindingKey。
新请求/计划/选择和恢复身份独立版本化，旧 checkpoint 不静默迁移或用新算法恢复。
新增字段通过既有持久化链保存，复用现有库，不自建调度平台或新增依赖。

### FDM-07：完整数据流与失败语义

```text
父候选及绑定的真实执行覆盖
 -> 选择可用维度/父样本
 -> 公开反馈投影（只在引导臂读历史）
 -> 同一合法编辑集合 + 同一生成模型
 -> 新候选准入与静态物化
 -> Agent 自主执行、真实工具与状态
 -> 原 Oracle / B / R / J / U
 -> 结算、持久化、下一轮
```

投影越界、摘要不符、生成拒绝、超时或缺证沿既有失败结算；不能重抽到出现增益才算一个机会。
Controller 不代替 Agent 读取或交付。未知/失败不作新覆盖，中断恢复保持选择、成本与反馈恰好一次。

### FDM-08：本地验收必须验证反馈改变决策

用固定父材料、公开输入与随机源，只改变获准历史覆盖：引导应在有明确优先级差异的反例中改变
实际编辑选择或 Provider 请求；随机的选择和请求必须不变。不能只断言日志多了 selected_dimension。
覆盖 B-only、R-only、J-new、重复/无新增、未知、私值拒绝、空索引回退及取消/恢复。

通过真实 Office runtime 和正式 Oracle 的受控模型端口，证明候选可导致不同真实状态与现有 B/R/J；
脚本化分叉只作为机制测试，不能报成真实模型成功率或引导优势。回归测试必须在对应缺陷版本上失败。

### FDM-09：一次有限开发实验决定是否值得继续

推荐开发上限：**2 对 × 2 臂 × 每臂 16 机会，共 64 机会，共享 3 小时硬截止**，沿用单 Episode
8+8 调用上限；完整 token/调用/费用预算、准备耗时、种子和运行顺序必须在运行包另行算清。
这是待批准上限，不是运行指令或足够证明优势的样本量；服务器仍交执行 AI 按获批运行包操作。

先冻结新机制，再取未用于调参的开发种子；两臂执行顺序跨配对平衡。所有结果保留，不因 W=0
中止覆盖比较，但 W=0 时本轮实验不能判通过；不因一臂落后补跑。人工中止仍保全且标不完整，不替换成新种子。

本轮完整开发实验逐对以各臂 `W/(W+F)` 判安全硬门槛：每一对中引导臂该比率必须大于 0，
且严格高于该对随机演化臂；不能用一对的领先抵消另一对的落后。
`W+F=0` 时比率为 null，不能判通过；Q、生成失败、基础设施失败和
`W/N_op` 分别报告。沿用 E2 证据口径，若 Q 或执行证据不完整，不能作完整效果验收。
两对的观测差异仅是开发门槛，不构成统计确认的引导优势。

读数直接回答：真实子代是否形成新 B/R/J、主成本曲线是否改善、是否只是根候选差异、重复及失败
是否减少。局部增益是诊断项，不是反馈可能有效的唯一渠道；根选择/预算利用贡献也分别报告。
反馈输入可控但仍无执行新增时，当前方案不算有效，不用“代码已通过”替代结果。

### FDM-10：正式优越性结论与停止投入

保留 `SOC-FBK-14` 的**预定共同累计 token 区间上 unique J 曲线面积**为正式主终点。
B/R、终点 J、重复率、W/U、完成率及全部成本并列；每机会 `sum(J[t])` 是辅助，不能混称正式主指标。
正式覆盖优势与本轮安全硬门槛分别判定；即使 J 改善，只要安全硬门槛未满足，也不能宣称本轮实验整体通过。
正式样本量、最小有意义效应、统计方法和停止规则在观察正式数据前单独冻结；不承诺 8 对必然足够。

建议正式配对使用共同的预生成起始候选与计划重启输入，模型各自真实执行；共享准备费用单列，
按固定规则分摊比较成本，不把一次真实生成伪记为两次调用。临时无父导致的额外根不假装是共同根。
相同材料不能保证模型轨迹相同，必须保留全部波动。开发数据不并入正式样本，历史差值不重算取胜。

本机制最多两轮有具体失败依据的开发修改；仍缺少真实新增就停止在同一简报任务上反复调话术，
转向具有自然任务分支的场景组合，另写规格。场景入选按业务合理性、完成性、可变材料影响行为、
证据可判定性决定，不能按哪一个场景引导获胜来筛。保留任务按任务/资料结构隔离，不仅换 seed。
